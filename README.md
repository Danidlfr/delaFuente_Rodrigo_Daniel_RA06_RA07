# Reserva de Videojuegos - Versión 2 (Catalogo)

## Descripción
Esta versión inicial del proyecto ficticio se centra en la implementación de la estructura base y la definición de los modelos de datos necesarios para el catálogo de videojuegos. 

## Versión
v2.0 - Gestion del catalogo

## Tecnologías Implicadas
*   **Java**: Implementación de la lógica de gestión de reservas.
*   **Git / GitHub**: Control de versiones y gestión de ramas por módulos.
*   **Markdown**: Documentación de funcionalidades y estructura de la aplicación.
