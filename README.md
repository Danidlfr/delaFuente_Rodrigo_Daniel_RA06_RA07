# Reserva de Videojuegos - Versión 1 (Catálogo)

## Descripción
Esta versión inicial del proyecto ficticio se centra en la implementación de la estructura base y la definición de los modelos de datos necesarios para el catálogo de videojuegos.
## Versión
v1.0 - Gestión de Catálogo

## Tecnologías Implicadas
*   **Java**: Lenguaje principal para la lógica de modelos.
*   **Git / GitHub**: Control de versiones y repositorio remoto.
*   **Markdown**: Documentación técnica y manual de estilo.
